# 修改记录

按时间整理的主要改动，每条后面是对应的 commit。细节以 `git log` 为准；这里按功能分组，方便查「某个功能是哪次改的、为什么这么改」。

版本号规则：TestFlight 每次发布升一个小版本（1.2 → 1.3），构建号同时 +1；同版本重新打包（例如修审核问题）只加构建号。只有用户明确要求时才改版本、打包。
