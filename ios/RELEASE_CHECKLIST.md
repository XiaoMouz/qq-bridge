# BetterChat iOS 1.15（23）与 Mac 1.1（2）发布检查

这次 Mac 开发修改了共享 iOS 代码，手机端会受到附件发送、语音状态、历史定位、同步、通知清理、通话状态及图片标注实现变化的影响。手机图片编辑功能仍保留。

## 已执行的验证

2026-10-15：

- iOS 模拟器：93 项测试、12 个套件通过，包括附件重试与发件箱确认、语音及 AI 语音、转文字缓存、历史分页与定位、消息观察、媒体生命周期、图片缩放和标注导出。
- QQBridgeKit：45 项测试、12 个套件通过，包括缓存删除失败、存储分页、发送幂等、重启恢复及同步竞态。
- 后端：类型检查及 150 项测试、33 个文件通过，包括 iOS/Mac 推送 topic 分流。
- Mac Catalyst：217 项测试、36 个套件通过；另有 7 组独立状态与文件检查通过。
- iOS Release 归档成功，15:26 经 Xcode Organizer 上传成功，显示 Uploaded to Apple，构建号 23。用途为 TestFlight，没有提交 App Store 上架审核。浏览器 App Store Connect 登录已失效，尚未核实 Apple 处理完成及可安装状态。
- 上传有两条非阻塞警告：LiveKitWebRTC、RustLiveKitUniFFI 缺少 dSYM，影响这些第三方框架的崩溃符号化。
- 正常 iOS 模拟器、真实账号：打开 Something，消息和测试图片/视频/文件显示；不存在消息的定位错误可关闭；图片原图加载后编辑入口可用。
- 正常启动、不带调试定位参数：Something → 群资料 → 查找聊天记录 → 搜索“验收” → 点击“回复测试”，正确显示目标历史消息且无定位错误。此前错误提示来自 `-debugJump 153:1` 在页面重现时再次触发，并非这次正常入口复验结果。
- 手机图片编辑页可打开、取消后返回查看器、关闭后返回聊天。
- 标注自动化测试验证不同画布尺寸下笔迹数据不变、合成图片不变；尚未把真实触摸绘画、撤销/重做、真机保存或发送标为已验收。

同步新增的两个场景在旧代码中确定性失败，修复后通过：首屏加载期间的新消息被忽略、Subscribe 差量回放只更新会话摘要而没有补齐已缓存消息。搜索定位也改为先等待会话追平，再判定目标缺失。上述测试不能证明所有网络条件下的偶现问题都已消失。

## 在 iPhone 上怎么检查

先在 TestFlight 确认版本为 **1.15（23）**。不要卸载旧版，直接更新以检查已有登录和本地数据库迁移。所有发送测试只在 **Something（群号 521409608）** 进行。

| 项目 | 操作 | 应看到的结果 |
|---|---|---|
| 更新与恢复 | 从旧版直接更新，打开 App；再结束 App 并重开 | 登录保留，会话和历史消息仍在，不需要重新建账号 |
| 会话同步 | 退出 Something 到列表再打开，连续重复几次；切后台一会再回前台 | 最新消息出现，列表预览与聊天内容一致，无重复消息或长期空白 |
| 断网恢复 | 手机暂时断网，打开会话，再恢复网络并回到 App | 恢复后自动追平；错误提示可以重试，不需重装或清缓存 |
| 历史与搜索 | 在 Something 右上角详情中查找已有消息；点结果；再向上翻历史 | 跳到正确消息并高亮；较早历史可继续加载；缺失目标提示可关闭 |
| 图片与标注 | 打开图片→编辑，画两条线→撤销→重做→完成；先检查预览再决定是否发送 | 编辑入口仍在，笔迹与图片对齐；取消不发送，完成后的图片无偏移或裁切 |
| 附件草稿 | 添加图片和 TXT，检查预览，移除其中一个，然后发送留下的测试文件 | 移除项不发送；发送成功后对应附件消失；失败时保留并可重试 |
| 失败重试 | 发送一份测试附件时断网，等失败再恢复并重试 | 不会因重试生成多份相同消息；进度不会被上一次任务覆盖 |
| 强退恢复 | 仅对测试附件，在上传/发送期间结束 App 后重开 | 不永久卡在“发送中”；查看实际聊天结果后再决定是否重试 |
| 语音播放 | 连续点两条语音，暂停/继续，拖进度，离开会话再回来 | 不会同时播放两条，不会被上一条迟到的回调替换 |
| 语音转文字 | 转文字→收起→重新展开；重启后再看；切换自动转文字设置 | 收起状态和缓存符合设置；失败可手动重试，不反复自动请求 |
| 录音 | 长按录音，分别取消和完成；第一次权限弹窗后再试 | 取消不会继续录；失败有提示；完成后可正常发送/播放 |
| AI 语音 | 选择角色并试听，切换角色；填写测试文本后发送一次 | 试听互斥，发送期间不能重复提交；失败保留输入 |
| 通知 | 将 App 置后台，收到新消息后点击通知；再检查其他未读消息通知 | 进入对应会话；只清理已读范围，不提前清掉未读通知 |
| 通话 | 和配合账号测试接听、挂断、静音与取消静音，切换前后台 | 系统来电与 App 不重复响铃；静音状态与实际麦克风一致；结束后状态收尾 |

发送回包丢失时，先看群里是否已经出现消息；不要为了测试重复手工发送。真机推送、相机、麦克风及对端通话需要实际设备和配合账号，本轮自动化测试不覆盖这些硬件结果。

- 安装包：`~/Downloads/BetterChat-2026-10-15/BetterChat-Mac-1.1-2-arm64.zip`（约 29 MB）。解压，将 `BetterChat.app` 拖到“应用程序”后打开。
- 当前产物仅支持 **Apple silicon（M 系列）和 macOS 27+**，不包含 Intel 架构。版本 **1.1（2）**。
- 此包经 Developer ID 签名并由 Apple 公证，未提交 Mac App Store。公证于 2026-10-15 15:52 显示 Ready to distribute，ID 为 `49E95B2D-A7A0-4EA6-9AE0-3B30793A4D66`。
- 已校验导出应用的深度严格代码签名、公证票据；Gatekeeper 返回 `accepted`、`source=Notarized Developer ID`。ZIP 完整性检查通过。公证票据已附在应用中，ZIP 只是分发容器。
- 已实际启动 Downloads 中的正式产物，确认原登录恢复、会话与最新测试媒体显示；图片/视频独立窗口、进入全屏、Esc 退出全屏及鼠标关闭返回聊天通过。
- 登录时使用其他机器能够访问的后端地址；`127.0.0.1:8080` 仅指向正在运行 App 的那台机器。若后端经私有网络提供，目标机器也需能访问该网络。
- 检查宽窄窗口切换、侧栏隐藏/展开、消息/联系人/设置切换、会话详情搜索。

- 下载文件应落在 Downloads；在“设置→下载”换目录后，再下载一个测试文件，并重启确认设置保留。
