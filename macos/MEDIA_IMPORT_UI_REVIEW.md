## 系统照片库视频补验

在正常应用的系统照片选择器中切到 Videos，选中一段 11 秒玩偶视频；界面确认 1 Video Selected 后点击 Add。聊天先显示“正在添加附件…”，随后出现“第 1 个附件：视频／准备发送”，首帧与所选素材一致，并有视频标记。

切到设置再回到 Something，视频仍在原草稿。再次打开选择器显示 Select Items、Add 禁用；Esc 取消后原视频保留。最后通过移除按钮清空，恢复录音入口，没有发送或上传。未保存包含用户照片库的截图。此次验证真实 Photos 视频交付与首帧，不代表远程云端未下载素材、视频发送或声音播放验收。
