# Mac 应用内消息横幅复验（2026-10-15）

## 问题与实现

正常根页面中注入受控本地横幅后，旧界面只暴露标题和正文文本；没有标准操作按钮，也没有可直接点击的关闭入口，只沿用 iOS 点按／上划手势。

新增独立 MacMessageBanner，正文区域为具名“快速回复：会话标题”按钮，正文作为辅助功能值；右侧提供独立“关闭消息横幅”按钮和悬停提示。保持原头像、玻璃容器、文字行数及根页面安全区布局。InAppBannerView 仅在 Mac 分支使用新组件，iOS 原手势不变。不改消息接收、计时、推送和路由模型。

## 实机证据

临时 DEBUG 菜单仅设置 AppModel.banner 为 chat 153 的本地测试内容，生产 MacGlobalOverlays 和快速回复调用链不替换；没有发送消息或推送，不声称验证新的推送到达。

- 修改前辅助功能树只有两段文本；修改后显示快速回复与关闭两个具名按钮。
- 1024×640 深色，鼠标关闭横幅后原聊天恢复。
- 440×480 深色／浅色，横幅边界、标题正文和关闭目标均可见，不覆盖聊天输入框。
- 正文按钮打开 Something 的实际快速回复，鼠标关闭回到原会话；再次显示横幅、重开快速回复后 Esc 关闭通过。
- 文字粘贴没有实际写入，辅助功能 setValue 返回不可设置；未据此宣称带文字草稿验收通过。最终输入框仍为空。

截图在 `/tmp/betterchat-ui-review/`：`banner-controls-before.png`、`banner-controls-wide.png`、`banner-controls-440.png`、`banner-controls-440-light.png`。界面恢复跟随系统、1024×640 和 Something。

临时菜单已移除，最终正常版本不含受控横幅入口。完整键盘导航及 VoiceOver 模式仍待验证；本轮标准按钮的辅助功能树证据不等同于完整辅助功能验收。

## 最终构建

Mac `/tmp/betterchat-banner-final-build.log` 与 iOS `/tmp/betterchat-banner-ios-build.log` 均 BUILD SUCCEEDED、退出码 0。Mac 严格签名与差异检查通过，Package.resolved 未改动。临时菜单源码检索为空。最终正常应用重开到 Something，另从会话右键的真实快速回复入口检查打开与鼠标关闭成功；它验证正常弹窗链路，不把右键入口当作新横幅到达证据。

此次仅调整 Mac 控件，未新增镜像实现的单元测试，也未重复未受影响的全量集；此前 212 项／35 组通过的范围见测试说明。

## 带会话目标的底部提示

受控本地提示使用生产 AppModel.showToast、默认显示时长和 MacGlobalOverlays；修改前辅助功能树将说明与“查看”分别识别为文本。Mac 的有目标提示现使用标准“查看会话”按钮，说明作为辅助功能值；无目标提示仍为普通内容。手机原点按逻辑保留。没有为此执行真实转发或发送消息。修改前截图 `toast-action-before.png`。

修复后辅助功能树显示“查看会话”按钮及提示正文值；从设置页实际点击后切回 Something。无目标提示仍只显示普通文本。440×480 截图发现蓝色查看文字叠在蓝色消息气泡透出的玻璃背景上对比度不足，Mac 改用系统主文字色，手机仍使用 tint。初次小窗口截图 `toast-action-440.png` 记录这一问题。

对比度调整后，440×480 深色与浅色截图分别为 `toast-action-440-fixed.png`、`toast-action-440-light.png`，查看文字与箭头在消息气泡透色背景上均清楚可辨。生产默认计时后提示自动消失，恢复 1024×640、跟随系统和空输入。临时提示菜单已移除。

提示最终构建：Mac `/tmp/betterchat-toast-final-build.log`、iOS `/tmp/betterchat-toast-ios-build.log` 均成功并正常退出。严格签名、差异检查通过，Package.resolved 未变；临时提示菜单已从源码移除，正常应用已重开到 Something 空输入主界面。本轮未新增单元测试或重复全量集。

后续通过正常输入框的实际位置点击解决自动化焦点问题，英文键入和中文粘贴成功，正常会话右键快速回复的带文字草稿、修改回传、关闭／重开／Esc 均已补验。原横幅受控步骤中的文字输入失败仍保留其历史边界，不把右键入口结果当作真实横幅触发证据。见 [输入与草稿复验](COMPOSER_INPUT_REVIEW.md)。
