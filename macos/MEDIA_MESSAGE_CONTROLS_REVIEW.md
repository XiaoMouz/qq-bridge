# 聊天媒体标准操作入口（2026-10-15）

## 实际缺口与调整

真实 Something 辅助功能树原先把图片、视频、文件和合并转发显示为图片或静态文本；源代码仅挂 onTapGesture。Mac 头像、回应和引用已使用标准按钮，但媒体尚未覆盖。

共享 UI 修饰器 MessageBlockAction 在 Mac 使用 plain Button，补名称、状态说明和悬停提示；手机保留点按手势。图片为“打开图片”，视频为“播放视频”及其时长，文件包含完整文件名和当前大小/下载状态，合并转发有明确查看入口。文件未就绪或不可用时不提供可执行打开动作，原请求/打开路由保持。

多选模式改为整行具名选择按钮，值包含已选状态和消息预览；内部媒体仅作为展示内容，从辅助功能树隐藏，防止绕过点击禁用误开媒体。手机仍用原行点击手势。合并转发内容的图片和视频也使用相同按钮入口。

## 正常构建的真实入口验证

- 聊天图片按钮打开独立图片窗口，鼠标关闭回到聊天；视频按钮打开独立视频窗口，鼠标关闭返回。
- 04-file.txt 按钮打开系统快速查看，显示测试文本；关闭后返回原位置。没有经文本编辑修改文件。
- 文件按钮右键仍有回复、转发、多选、复制等菜单；只选择多选，未执行任何消息写操作。
- 多选时辅助功能树仅暴露“选择消息”，不再暴露图片/视频/文件打开按钮。点击图片行计数从 1 到 2，点击图片卡片取消后回到 1，未打开媒体；取消多选后恢复原按钮。
- 合并转发按钮打开真实既有测试记录。内部图片、视频分别通过新按钮打开独立窗口，鼠标关闭后仍是同一份记录；完成按钮关闭、重开与 Esc 返回均通过。
- 最后恢复 Something 最新消息及空草稿，没有发送、撤回、回应或修改旧消息。
